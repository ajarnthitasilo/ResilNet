# ESP32 Standalone (Data Mule)

โหนด **mule** เก็บข้อความ/ประกาศบนเครื่องแล้ว sync กับมือถือผ่าน BLE เมื่อมีคนเดินผ่าน — เหมาะกับออฟไลน์ยาวๆ

ชื่อที่โฆษณาโดยทั่วไป: `RN-MULE` / บริการ BLE ของโหนด ResilNet

## สิ่งที่ต้องมี

- บอร์ด ESP32 ที่แฟลช `resilnet_esp32_standalone.bin`
- แอป ResilNet บนมือถือ (เปิด Bluetooth)
- เสาอากาศในตัวบอร์ดเพียงพอสำหรับ BLE

## ติดตั้งเฟิร์มแวร์ครั้งแรก

1. ได้ไฟล์ `.bin` จาก [หน้าเฟิร์มแวร์](../firmware/) หรือ baseline ในแอป
2. แฟลชด้วยคอมพิวเตอร์ (PlatformIO / esptool) **หรือ** ใช้ **BLE OTA ในแอป** ถ้าบอร์ดมีเฟิร์มแวร์ OTA อยู่แล้ว
3. เปิดไฟ → มือถือควรเห็นโหนดใกล้ตัวตอน sync

ดูรายละเอียด OTA เทคนิคเพิ่มใน repo: `docs/esp32_ble_ota.md`

## การใช้งานประจำ

1. เปิดแอปใกล้โหนด
2. ให้แอป sync (ดัน/ดึงข้อความและ bulletin ตามโปรโตคอล mule)
3. โหนดเก็บประกาศสาธารณะไว้ช่วงสั้น (~3 วัน) เพื่อคนมาทีหลัง

## ไม่สับสนกับ LoRa Gateway

| | Standalone Mule | LoRa Gateway |
|--|-----------------|--------------|
| วิทยุ LoRa | ไม่ | ใช่ |
| บทบาทหลัก | เก็บส่งต่อผ่าน BLE | สะพาน BLE/UDP ↔ LoRa (+ mesh hop) |
| ไฟล์ bin | `…_standalone.bin` | `…_lora_gateway.bin` |
