# Local Wi‑Fi (LAN ระหว่างมือถือ)

**Local Wi‑Fi** ให้มือถือในเครือข่ายเดียวกันค้นหาและคุยกันผ่าน LAN (UDP) โดย**ไม่ต้อง**มี Mac/Pi และ**ไม่ใช่** SoftAP ของ ESP32

เปิดจาก **Settings → Local Wi‑Fi** (ชื่อตามภาษา UI)

## โหมดหลัก

| โหมด | ความหมาย |
|------|----------|
| **ใกล้กัน / ฮอตสปอต** | เครื่องหนึ่งแชร์ Personal Hotspot อีกเครื่องเข้าร่วม แล้วให้แอปค้นหาบนเน็ตนั้น |
| **เราเตอร์** | ทุกเครื่องต่อ Wi‑Fi เราเตอร์เดียวกัน (เราเตอร์ไม่จำเป็นต้องมีเน็ตออกนอก) |

## สิ่งที่ควรรู้

- ใช้สำหรับค้นหาเพื่อนบน LAN และส่งแชต sealed เมื่อมีคีย์แล้ว
- **ไม่แทนที่** Home node (Reticulum) และไม่แทนที่ Nostr เมื่อคนอยู่คนละเครือข่าย
- บางเราเตอร์เปิด **AP/client isolation** — มือถือต่อ Wi‑Fi เดียวกันแต่คุยกันไม่ได้ ต้องปิด isolation หรือใช้โหมดฮอตสปอต
- ถ้ายังไม่มีคีย์เพื่อน: สแกน QR / เพิ่มสมาชิกตามปกติหลังจากค้นเจอ

## เทียบกับ Home node

| | Local Wi‑Fi | Home node |
|--|-------------|-----------|
| อุปกรณ์พิเศษ | ไม่ต้อง | ต้องมี Mac/Pi + bridge |
| โปรโตคอล | UDP ในแอป | HTTP → LXMF / Reticulum |
| ระยะ | เฉพาะ LAN เดียวกัน | LAN + เส้นทาง RNS ระหว่างโหนดบ้าน |

รายละเอียด Home node: [Reticulum / Home node](reticulum-home-node.md)
