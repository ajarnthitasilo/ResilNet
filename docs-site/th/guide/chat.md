# แชต 1:1 (เข้ารหัสปลายทางถึงปลายทาง)

ข้อความส่วนตัวระหว่างคุณกับเพื่อนหนึ่งคนถูก **seal (เข้ารหัส)** ก่อนออกจากเครื่อง — โหนด ESP32 / LoRa ส่งต่อได้แบบ opaque โดยไม่ถอดรหัส

## เริ่มคุย

1. เพิ่มเพื่อน (ค้นหาใกล้ตัว / QR / ช่องทางที่มีในแอป)
2. เปิดห้องแชต → พิมพ์หรือส่งเสียง / รูปตามที่รองรับ
3. เมื่อมีเน็ต ระบบมักส่งผ่าน **Nostr**; เมื่อออฟไลน์ใช้ mesh / ESP32 / คิวในเครื่อง

## ความหมายของติ๊กสถานะ

| สถานะ | ความหมาย |
|--------|----------|
| นาฬิกา / รอ | ยังค้างในเครื่อง หรือรอส่ง |
| ติ๊กเดียว (เทา) | ส่งออกแล้ว / ถูก relay |
| ติ๊กคู่ (เทา) | **Delivered** — เครื่องผู้รับได้รับแล้ว |
| ติ๊กคู่ (ฟ้า) | **Read** — ผู้รับเปิดห้องแชตนั้นแล้ว |

> ติ๊กทำงานทั้งโหมด **บันทึกประวัติเปิด** และ **ปิด** (ข้อความอยู่แค่ในเซสชัน)

## สิ่งที่แชต 1:1 ไม่ใช่

- ไม่ใช่ประกาศสาธารณะบน #mesh (ดู [ประกาศสาธารณะ](mesh.md))
- ไม่ใช่โพสต์บนกระดานชุมชน (ดู [กระดาน](boards.md))

## เมื่อส่งไม่ถึง

- ตรวจว่าอีกฝ่ายออนไลน์ (Nostr) หรืออยู่ในระยะ BLE / มีโหนด ESP32 คั่นกลาง
- เปิดประวัติข้อความถ้าต้องการเก็บหลังปิดแอป (ตั้งค่าในแอป)
- ดู log `[ACK]` ตอนแก้ปัญหาติ๊ก: enqueue → flush → apply
