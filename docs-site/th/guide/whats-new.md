## 1) Apple Watch — ของใหม่หลัก

- ติดตั้งคู่กับแอป iPhone (target `ResilNetWatch`)
- แท็บ **Status**: โหมดขนส่ง, คนออนไลน์, unread, สถานะ iPhone
- แท็บ **Chats**: ดู Directs ล่าสุด ส่งข้อความสั้น / quick reply
- **เข้ารหัสและส่งผ่าน mesh อยู่บน iPhone** — Watch ไม่มีคีย์แยก
- ควรเปิดแอป ResilNet บน iPhone อย่างน้อยครั้งหนึ่ง และให้ Reachable

อ่านเต็ม: [apple-watch.md](apple-watch.md)

---

## 2) Onboarding แบบโต้ตอบ

ครั้งแรก (หรือเมื่อรีเซ็ต onboarding) แอปพาชม:

Welcome → Identity → ช่องทาง → Toolbar → Compose → Direct → กระดาน → Local Wi‑Fi → Transport → Area → Bridges/ฮาร์ดแวร์ → ความปลอดภัย → **Apple Watch** → Ready

มีแผงสาธิตสั้นๆ ช่วยจำไอคอนและเมนูหลัก

---

## 3) เชื่อม Nostr ผ่าน Tor

- **Settings → เชื่อม Nostr ผ่าน Tor**
- ใช้ SOCKS `127.0.0.1:9050` (Orbot หรือ Tor ของระบบ)
- ช้ากว่า แต่ซ่อน IP จาก relays
- **ต้องเปิด Tor ไว้** — แอปจะไม่ถอยไป clearnet ถ้า SOCKS ใช้ไม่ได้

---

## 4) สิ่งที่ยังเหมือนรอบ 1.9.64 (อย่าคาดหวังหาย)

- Home node (Reticulum / LXMF) และ Local Wi‑Fi ตามคู่มือเดิม
- แตะสองครั้งที่ชื่อ ResilNet = soft refresh; กดค้าง = กู้หนัก; สามครั้ง = panic wipe
- ยังไม่มีบัญชีอีเมล/โทร
- แชต 1:1 ยัง E2EE; **public mesh bulletin** ยัง plaintext + ลายเซ็น
- LoRa ของ ResilNet **ยังไม่เข้ากัน Meshtastic บน RF** (มีสะพานข้อความใน Settings แยก — plaintext)
