คู่มือ docs-site รอบที่แล้วระบุแอป/เฟิร์มแวร์ประมาณ **1.9.49**

## สรุปใหญ่สำหรับผู้ใช้

| หัวข้อ | สถานะใน 1.9.64 |
|--------|----------------|
| **Home node (Reticulum / LXMF)** | มีใน Settings — ทางเลือก Mac/Pi บน Wi‑Fi | 
| **Local Wi‑Fi** | มีใน Settings — ค้นหา/คุยมือถือใน LAN |
| **ภาษาในแอป** | ขยายหลายภาษา (ตามระบบ + เลือกใน Settings); ไทย/อังกฤษยังเป็นฐาน |

## 1) Home node (Reticulum / LXMF) — ของใหม่หลัก

**ก่อนหน้า (คู่มือ 1.9.49):** ชั้นสื่อสารที่เขียนไว้คือ BLE → ESP32/LoRa → Nostr เท่านั้น ไม่มี Reticulum ในคู่มือผู้ใช้

**ตอนนี้ (1.9.64):**

- เมนู **Settings → Home node**
- ใส่ที่อยู่ Mac/Pi ที่รัน bridge, ตรวจออนไลน์, คัดลอกที่อยู่โหนด, ผูกเพื่อน
- แอปส่ง/ดึง **ซองแชตที่เข้ารหัสแล้ว** ผ่าน HTTP ไปยัง bridge (LXMF บน Reticulum)
- มี lab ใน repo: `labs/reticulum_lxmf/` สำหรับผู้ดูแลโหนด

อ่านเต็ม: [reticulum-home-node.md](reticulum-home-node.md)

จุดที่ต้องเน้นกับชุมชน:

- ไม่ได้แทน E2EE
- ไม่ได้รัน LXMF บน Heltec LoRa
- ต่างจาก Local Wi‑Fi

## 2) Local Wi‑Fi (LAN)

**ของใหม่หลัง 1.9.49** — ไม่ได้อยู่ในคู่มือเดิม

- Settings → Local Wi‑Fi  
- โหมดฮอตสปอตใกล้กัน / โหมดเราเตอร์  
- ค้นหาเพื่อนบน LAN แล้วคุย 1:1 เมื่อมีคีย์  

อ่าน: [local-wifi.md](local-wifi.md)

---

## 3) ภาษาและการตั้งค่า

- ค่าเริ่มต้น: **ตามภาษาเครื่อง** เมื่อแอปมีภาษานั้น; ไม่มีในชุด → อังกฤษ  
- Settings → ภาษา: เลือกตามระบบ หรือล็อกภาษา  
- ชุดภาษาขยายมาก (รวมภูมิภาคเอเชีย/ยุโรป ฯลฯ); บางภาษาเป็นร่างแปลเครื่อง — ไทยยังเป็นชุดที่ดูแลหลัก  
- กะเหรี่ยง (`ksw`) / เมียนมาร์ (`my`) มีในรายการแล้ว (คุณภาพแปลมือยังทยอย)

---

## 4) การกู้เมื่อแอปดูค้าง / วิทยุเงียบ

- **แตะสองครั้ง** ที่ชื่อ ResilNet = รีเฟรชวิทยุ/ค้นหา (soft)  
- **กดค้าง** = กู้หนักกว่า  
- **แตะสามครั้ง** = ล้างข้อมูลฉุกเฉิน (panic wipe) — ระวังอย่าสับสนกับสองครั้ง  
- มีคำใบ้ในแอป / Info  

(คู่มือ 1.9.49 ยังไม่เน้น soft refresh แบบนี้)

---

## 5) Area, เสียง, BLE, อื่นๆ ที่ผู้ใช้สัมผัสได้

- Area (#geo): รีเฟรช geohash เมื่อเปิดแอปในโหมด Area; ปรับความแม่นยำ/ข้อความว่างเมื่อยังไม่มี GPS  
- ข้อความเสียง: ขอสิทธิ์ไมค์ชัดเจน; UI อัด/พรีวิวดีขึ้น  
- แถบสถานะ BLE: แยกกรณีต้องขอสิทธิ์ / ถูก pause / กำลังสแกน  
- การกู้ session / hard recover จาก Settings (ตามที่มีในแอป)

---

## 6) สิ่งที่**ยังเหมือนเดิม** (อย่าคาดหวังผิด)

- ยัง **ไม่มีบัญชี** อีเมล/โทร  
- แชต 1:1 ยัง E2EE; #mesh bulletin สาธารณะยังไม่เข้ารหัสเนื้อหา  
- LoRa ของ ResilNet **ยังไม่เข้ากัน Meshtastic** (มีสะพานทดลองแยกถ้าทีมเปิดใช้)  
- กระดานชุมชน Open/Locked แนวคิดเดิม
