# กระดานชุมชน (Announcement boards)

กระดานมีเจ้าของ และเลือกได้สองโหมด (หรือทั้งคู่ ตามที่เจ้าของเปิด):

- **Open** — โพสต์อ่านได้โดยผู้ติดตาม โดยไม่ต้องใช้คีย์เข้ารหัสกระดาน
- **Locked** — โพสต์เข้ารหัส เฉพาะผู้ได้รับสิทธิ์

## เชิญคนเข้ากระดาน (อ่านง่าย)

เจ้าของแชร์ได้สามแบบ (อย่าแชร์คีย์ส่วนตัวของกระดาน):

1. **ข้อความเชิญ** — คัดลอกแล้วส่งในแชต / ไลน์ ฯลฯ
2. **QR code** — ให้สแกนในแอป
3. **Deep link** — `resilnet://board/invite?...`

ผู้รับเปิดลิงก์หรือสแกน QR → ยืนยัน → ติดตามกระดาน

> รูปแบบ JSON ยาวแบบเก่ายังใช้ได้เพื่อความเข้ากันได้ แต่ผู้ใช้ทั่วไปควรใช้ QR / ข้อความเชิญ / deep link

## สิ่งที่กระดานไม่ใช่

- ไม่แทนที่ประกาศฉุกเฉินแบบ plaintext บน #mesh ทั้งวง (ดู [mesh](mesh.md))
- ไม่ใช่แชต 1:1 เข้ารหัสส่วนตัว
