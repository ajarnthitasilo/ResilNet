# Area (geohash)

**Area** คือฟีดตามเซลล์ geohash — คนออนไลน์ในพื้นที่เดียวกัน และข้อความสาธารณะในพื้นที่นั้น

เปิดจากไอคอน Location / สลับไปโหมด Area ใน Community (ชื่อตามภาษา UI)

## สิ่งที่ต่างจาก #mesh bulletin

| | Area | Public mesh bulletin |
|--|------|----------------------|
| ขอบเขต | เซลล์ geohash (ปรับความละเอียด / pin / teleport ได้) | เพื่อน/วิทยุใกล้ตัวใน mesh |
| ข้อความสาธารณะ | fan-out **sealed E2EE รายคน** — ไม่ใช่ plaintext | **plaintext + ลายเซ็น** |
| แชต 1:1 | แตะคนออนไลน์ในพื้นที่ | แตะเพื่อนในรายชื่อ #mesh |

อย่าใส่ความลับใน bulletin ของ mesh — แต่ Area public fan-out ยังผนึกรายผู้รับ (ต้องมีคีย์เพื่อน)

## การใช้งานสั้นๆ

1. อนุญาต Location เมื่อระบบขอ (ใช้คำนวณ geohash)
2. เปิดชีต Area: ปรับความละเอียด, pin เซลล์, หรือใส่ geohash เอง (teleport)
3. รีเฟรช GPS ถ้าเซลล์ว่างหรือผิดที่
4. ส่ง 1:1 หรือโพสต์สาธารณะในพื้นที่ตาม UI

## โหมดขนส่ง (Transport)

ใน Community สามารถเลือกประมาณ **Mesh / Internet / Auto** ว่าทราฟฟิกสาธารณะจะพึ่งวิทยุใกล้ตัวหรือ Nostr เป็นหลัก — ดูไอคอน Transport บนแถบเครื่องมือ
