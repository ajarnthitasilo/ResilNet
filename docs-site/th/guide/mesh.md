# #mesh และประกาศสาธารณะ (Public bulletin)

## ความต่างของช่องทาง (สำคัญ)

| ช่อง | เข้ารหัส? | ใครอ่านได้ | เก็บบน ESP32 mule? |
|------|-----------|------------|---------------------|
| **Public mesh bulletin** | ไม่ (plaintext + ลายเซ็นในตัว) | ทุกเครื่องในระยะ mesh | ใช่ (TTL สั้น ~3 วัน) |
| **Mesh private / 1:1** | ใช่ (E2EE) | เฉพาะคู่สนทนา | ตามคิวข้อความทั่วไป |
| **กระดาน Open** | ไม่ | ผู้ติดตามกระดาน | ไม่ใช่บทบาท mule bulletin |
| **กระดาน Locked** | ใช่ | ผู้มีคีย์กระดาน | เช่นเดียวกับกระดาน |

ประกาศผ่าน mesh ออกแบบมาเพื่อ **ภัยพิบัติ / ออฟไลน์** — คนเข้ามาทีหลังในระยะวิทยุยังควรเห็นประกาศที่โหนดเก็บไว้

## วิธีโพสต์ (ผู้ใช้)

1. เปิด Notices / ช่อง #mesh ตาม UI ในแอป
2. เลือกขอบเขต **mesh** (ไม่ใช่ geo ถ้าต้องการออกอากาศใกล้ตัว)
3. โพสต์ข้อความสั้นๆ — จะถูกทำเครื่องหมายว่าเป็นประกาศสาธารณะ

## สิ่งที่ควรรู้

- ไม่ต้องแลก public key กับทุกคนก่อนโพสต์
- มีป้ายบอกว่าเป็นสาธารณะ / ไม่เข้ารหัสเนื้อหา
- อย่าใส่ข้อมูลลับใน bulletin
