# #mesh และประกาศสาธารณะ (Public bulletin)

## ความต่างของช่องทาง (สำคัญ)

| ช่อง | เข้ารหัส? | ใครอ่านได้ | เก็บบน ESP32 mule? |
|------|-----------|------------|---------------------|
| **รายชื่อ #mesh** | — (ไม่ใช่ฟีดโพสต์) | เพื่อนในรัศมี BLE — แตะเพื่อแชต 1:1 E2EE | — |
| **Public mesh bulletin** (Notices) | ไม่ (plaintext + ลายเซ็นในตัว) | ทุกเครื่องในระยะ mesh | ใช่ (TTL สั้น ~3 วัน) |
| **Area (geohash)** | fan-out สาธารณะ = sealed รายคน | คนในเซลล์พื้นที่ | ไม่ใช่บทบาท mule bulletin |
| **Mesh private / 1:1** | ใช่ (E2EE) | เฉพาะคู่สนทนา | ตามคิวข้อความทั่วไป |
| **กระดาน Open** | ไม่ | ผู้ติดตามกระดาน | ไม่ใช่บทบาท mule bulletin |
| **กระดาน Locked** | ใช่ | ผู้มีคีย์กระดาน | เช่นเดียวกับกระดาน |

ในแอป ช่อง **#mesh** เป็นรายชื่อเพื่อนใกล้ตัว (**ไม่มีช่องพิมพ์สาธารณะในฟีดนี้**) — ประกาศสาธารณะโพสต์ผ่าน **Notices** ขอบเขต mesh

ประกาศผ่าน mesh ออกแบบมาเพื่อ **ภัยพิบัติ / ออฟไลน์** — คนเข้ามาทีหลังในระยะวิทยุยังควรเห็นประกาศที่โหนดเก็บไว้

## วิธีโพสต์ bulletin (ผู้ใช้)

1. เปิด **Notices** ในแอป
2. เลือกขอบเขต **mesh** (ไม่ใช่ geo ถ้าต้องการออกอากาศใกล้ตัว)
3. โพสต์ข้อความสั้นๆ — จะถูกทำเครื่องหมายว่าเป็นประกาศสาธารณะ

สำหรับฟีดพื้นที่ตาม geohash ดู [Area](area.md)

## สิ่งที่ควรรู้

- ไม่ต้องแลก public key กับทุกคนก่อนโพสต์ bulletin
- มีป้ายบอกว่าเป็นสาธารณะ / ไม่เข้ารหัสเนื้อหา
- อย่าใส่ข้อมูลลับใน bulletin
- ส่งผ่าน hybrid router ได้ (BLE + LoRa + Nostr เมื่อออนไลน์) ตามสถานะในแอป
