# คำถามที่พบบ่อย

## ไม่เห็นเพื่อนใกล้ตัว

- เปิด Bluetooth ทั้งสองเครื่อง
- Android: ตรวจสิทธิ์ Location / Nearby devices
- อยู่ใกล้กันและไม่ได้อยู่ในโหมดประหยัดพลังงานที่ตัด BLE
- ลองรีเฟรชรายชื่อใกล้ตัวในแอป

## ส่งข้อความแล้วอีกฝ่ายไม่ได้รับ

- ถ้าพึ่งอินเทอร์เน็ต: ตรวจว่ามีเน็ตและ Nostr ทำงาน
- ถ้าออฟไลน์: ต้องมี BLE ถึงกัน หรือมี ESP32 / LoRa คั่นกลาง
- ข้อความอาจค้างคิว — เปิดแอปอีกครั้งเมื่อมีทางส่ง

## ติ๊กไม่อ่าน (ไม่เป็นสีฟ้า)

- ผู้รับต้อง **เปิดห้องแชตนั้น** (หรือแชตเปิดอยู่แล้ว)
- ต้องมีทางส่ง ACK กลับ (เน็ต / BLE / gateway)
- ลองทั้งโหมดบันทึกประวัติเปิดและปิด — ทั้งคู่ควรรองรับแล้วใน 1.9.49+

## OTA ไม่สำเร็จ

- แบตบอร์ดและมือถือพอ
- อยู่ใกล้ ESP32 ตลอดการส่ง
- ใช้ไฟล์ที่ตรงชนิดโหนด (mule ≠ LoRa)
- ถ้า checksum ไม่ตรง แอปจะบล็อกการแฟลช
- คู่มือเต็ม + ลิงก์ดาวน์โหลด: [แฟลช / BLE OTA](../guide/esp32-ota.md)

## ไม่มีเน็ต แต่ต้องแฟลชเฟิร์มแวร์

- ใช้ **baseline ที่ฝังในแอป** (ตั้งค่า → ดาวน์โหลดเฟิร์มแวร์ ESP32)
- หรือก็อปไฟล์ `.bin` จากเครื่องอื่น / จาก [หน้าเฟิร์มแวร์](../firmware/) เมื่อมีเน็ต

## กระดานเชิญเป็น JSON ยาวอ่านไม่ออก

- ให้เจ้าของใช้ **คัดลอกข้อความเชิญ / แสดง QR / deep link** แทนการวาง JSON ดิบ

## LoRa ส่งแล้วไม่มีใครได้ยิน

- ตรวจเสาอากาศ
- ความถี่ / SF ต้องตรงกันทุกโหนด
- TTL และการจำกัดอัตรา relay — ดู Serial log บนเกตเวย์
