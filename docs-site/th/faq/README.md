# คำถามที่พบบ่อย

## ไม่เห็นเพื่อนใกล้ตัว

- เปิด Bluetooth ทั้งสองเครื่อง
- Android: ตรวจสิทธิ์ Location / Nearby devices
- อยู่ใกล้กันและไม่ได้อยู่ในโหมดประหยัดพลังงานที่ตัด BLE
- ลองรีเฟรชรายชื่อใกล้ตัวในแอป หรือ **แตะชื่อ ResilNet สองครั้ง** (soft refresh)

## ส่งข้อความแล้วอีกฝ่ายไม่ได้รับ

- ถ้าพึ่งอินเทอร์เน็ต: ตรวจว่ามีเน็ตและ Nostr ทำงาน
- ถ้าเปิด **Nostr ผ่าน Tor**: ต้องเปิด Orbot/Tor (SOCKS 9050) — แอปจะไม่ถอยไป clearnet
- ถ้าออฟไลน์: ต้องมี BLE ถึงกัน หรือมี ESP32 / LoRa คั่นกลาง
- ข้อความอาจค้างคิว — เปิดแอปอีกครั้งเมื่อมีทางส่ง

## ติ๊กไม่อ่าน (ไม่เป็นสีฟ้า)

- ผู้รับต้อง **เปิดห้องแชตนั้น** (หรือแชตเปิดอยู่แล้ว)
- ต้องมีทางส่ง ACK กลับ (เน็ต / BLE / gateway)
- ลองทั้งโหมดบันทึกประวัติเปิดและปิด — ทั้งคู่ควรรองรับแล้วใน 1.9.49+

## Apple Watch ขึ้น Waiting for iPhone

- เปิด ResilNet บน iPhone แล้ว Refresh บน Watch
- ตรวจว่า iPhone Reachable (พกใกล้กัน / ไม่ kill แอปทันที)
- สร้าง Direct บน iPhone ก่อนจึงจะมีรายการแชตบน Watch
- คู่มือ: [Apple Watch](../guide/apple-watch.md)

## Home node (Reticulum) ออฟไลน์ / เพื่อนไม่ได้รับ

- Mac/Pi รัน bridge อยู่หรือไม่ และ IP ใน Settings ถูกหรือไม่
- มือถือกับโหนดอยู่ Wi‑Fi เดียวกันหรือเข้าถึงพอร์ตได้หรือไม่
- ทั้งสองฝั่ง **ผูกที่อยู่โหนด** ของกันและกันแล้วหรือยัง
- อย่าสับสนกับ Local Wi‑Fi — คนละเมนูใน Settings
- คู่มือเต็ม: [Home node / Reticulum](../guide/reticulum-home-node.md)

## Local Wi‑Fi หาเพื่อนไม่เจอ

- โหมดฮอตสปอต: อีกฝ่ายเข้าฮอตสปอตแล้วหรือยัง
- โหมดเราเตอร์: อาจโดน **client isolation** — ปิดที่เราเตอร์หรือใช้ฮอตสปอต
- iOS: อนุญาต **Local Network** ให้ ResilNet
- คู่มือ: [Local Wi‑Fi](../guide/local-wifi.md)

## OTA ไม่สำเร็จ

- แบตบอร์ดและมือถือพอ
- อยู่ใกล้ ESP32 ตลอดการส่ง
- ใช้ไฟล์ที่ตรงชนิดโหนด (mule ≠ LoRa)
- ถ้า checksum ไม่ตรง แอปจะบล็อกการแฟลช
- คู่มือเต็ม + ลิงก์ดาวน์โหลด: [แฟลช / BLE OTA](../guide/esp32-ota.md)

## ไม่มีเน็ต แต่ต้องแฟลชเฟิร์มแวร์

- ใช้ **baseline ที่ฝังในแอป** (ตั้งค่า → ดาวน์โหลดเฟิร์มแวร์ ESP32)
- หรือก็อปไฟล์ `.bin` จากเครื่องอื่น / จาก [หน้าเฟิร์มแวร์](../firmware/) เมื่อมีเน็ต
- เฟิร์มแวร์ปัจจุบันบน CDN ยังเป็น **1.9.49** แม้แอปจะเป็น 1.9.75

## กระดานเชิญเป็น JSON ยาวอ่านไม่ออก

- ให้เจ้าของใช้ **คัดลอกข้อความเชิญ / แสดง QR / deep link** แทนการวาง JSON ดิบ

## LoRa ส่งแล้วไม่มีใครได้ยิน

- ตรวจเสาอากาศ
- ความถี่ / SF ต้องตรงกันทุกโหนด
- TTL และการจำกัดอัตรา relay — ดู Serial log บนเกตเวย์
- สะพาน Meshtastic ในแอป (Settings) เป็นข้อความ plaintext แยก — **ไม่** ทำให้ RF เข้ากัน Meshtastic
